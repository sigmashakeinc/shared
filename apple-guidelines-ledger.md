# Apple App Store Review Guidelines — Compliance Ledger (SigmaShake Desktop, macOS)

This is the canonical "all guidelines accounted for" artifact for the Mac App Store lane of
SigmaShake Desktop (`sigmashake-desktop-mac/`). Every section of the Apple App Store Review
Guidelines is enumerated below with an applicability verdict, the current measured state from
repo evidence at HEAD, and the check that owns it.

- **Source:** https://developer.apple.com/app-store/review/guidelines/
- **Fetched:** 2026-06-23 (live page; the page displays no last-updated date). Most recent prior
  fetch: 2026-06-11. Re-fetch on 2026-06-23 showed **no observable change** to any section since
  2026-06-11 — all section IDs, clause counts (2.4.5 still has nine items (i)-(ix)), and
  intentionally-omitted placeholders (2.5.7, 2.5.10, 4.2.4, 4.2.5, 4.4.3, 4.6) are unchanged.
  The AI-sharing disclosure requirement in 5.1.2(i) and all other clauses relevant to this app
  (2.1, 2.4.5, 2.5.1, 2.5.2, 3.1, 4.2, 4.8, 5.1.1, 5.6) are confirmed unchanged. All
  mapped-cluster verdicts from the 2026-06-11 through 2026-06-15 rounds remain current.
- **Maintenance rule:** the `macguide-guidelines-cartographer` re-fetches the live guidelines
  page and diffs it against this ledger every program round. Any added, removed, or changed
  section forces a re-verdict of the mapped cluster and an update to this file before the round
  closes. The `store-guidelines-ledger-current` parity entry is the freshness gate.
- **Cross-OS thesis:** the Apple App Review bar is adopted as the parity requirement for the
  Windows (C#/.NET MSIX, Microsoft Store) and Linux (Go/Wails, Flathub-target) shells via the
  `store-*` platform-parity entries in `sigmashake-workspace/src/platform-parity-catalog.ts`.
  Where Microsoft Store Policies (v7.19) or Flathub requirements have a real analogue, the
  per-OS verification cites it; where a platform has no analogue, the Apple bar is adopted
  explicitly. See "Cross-OS analogue map" below.
- **Honesty rule:** statuses are measured against the repository at HEAD. The current MAS
  submission's App Review outcome is external and unconfirmed — nothing here claims store
  approval. Honest red beats fake green. Unknowns stay marked unknown.

Legal entity note: SigmaShake is a sole-operator individual entity, USA. No surface in this
program may carry an incorporation claim.

## Cross-OS analogue map

The Apple bar is the parity requirement for all three shells. Per cluster: the nearest
Microsoft Store policy (v7.19, effective 2025-10-14) and Flathub requirement, or an explicit
"no analogue — Apple bar adopted" note. Known platform gaps at HEAD: Linux has NO Flathub-ready
Flatpak manifest for the Wails shell (the legacy `sigmashake-dist/flatpak/` manifests package the
retired Electrobun bundle for the self-hosted flatpak.sigmashake.com repo, not Flathub), so every
Flathub-cited verification below is currently blocked on creating one; the Windows updater
gate (`AppPackage.cs IsPackaged`, runtime package-identity detection) is the correct dormant-
updater pattern the Mac MAS lane should mirror.
